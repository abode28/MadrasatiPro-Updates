مدرستي Pro — خطوات الرفع الأول إلى مستودعك
===========================================
المستودع: https://github.com/abode28/MadrasatiPro-Updates

1) فك ضغط MadrasatiPro_GitHub_Ready.zip في مجلد جديد.
2) افتح رابط المستودع أعلاه وتأكد أنك مسجل الدخول بحسابك.
3) اضغط Add file ثم Upload files.
4) من مستكشف الملفات، افتح المجلد الذي فككت الضغط داخله. اسحب الملفات والمجلدات الموجودة داخله إلى منطقة الرفع في GitHub (لا تسحب ملف ZIP نفسه).
   مهم: ارفع مجلد .github أيضاً؛ بداخله خطوات البناء والنشر.
5) انتظر حتى تظهر الملفات في صفحة الرفع. اكتب في Commit message: Initial Madrasati Pro upload
6) اضغط Commit changes لإتمام رفع الملفات.
7) افتح Actions. إذا ظهرت رسالة تطلب تفعيل workflows، اختر تفعيل GitHub Actions.
8) افتح Build and publish Madrasati Pro update ثم Run workflow. أدخل 1.2.0 لهذا التحديث، واترك ملخص التحديث الافتراضي ثم شغّل العملية.
9) انتظر حتى تظهر علامة النجاح الخضراء. بعدها افتح Releases وتأكد أن الإصدار يحتوي على ملف Setup وملف .sha256.

بعد نشر الإصدار الأول:
- من البرنامج المثبّت، زر تحديث البرنامج يفحص وجود إصدار أحدث وينزّله بعد موافقتك.
- لإصدار تحديث قادم، ارفع تغييرات الكود إلى المستودع ثم شغّل سير العمل برقم أعلى، مثلاً 1.2.0.
- هذا الزر لا ينشر الكود؛ هو لتلقي إصدار منشور. النشر يتم عبر Actions.

حماية بيانات المدارس:
- لا ترفع school_manager.db أو ملفات بيانات الطلاب أو أي كلمات مرور أو ملفات نسخ احتياطية إلى GitHub.
- الإصدار الأول يلزم تثبيته مرة واحدة على النسخ القديمة التي لا تحتوي أصلاً على زر التحديث.
