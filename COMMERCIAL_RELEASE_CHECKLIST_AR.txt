قائمة تجهيز مدرستي Pro للبيع التجاري
====================================

الإصدار الحالي: 1.0.0 — حزمة بناء أولى

قبل تسليم البرنامج إلى مدرسة:
[ ] غيّر اسم الناشر في installer\SchoolManagerPro.iss إلى الاسم التجاري الحقيقي.
[ ] أضف رقم الهاتف والبريد وموقع الدعم الفني وسياسة الخصوصية.
[ ] ابنِ ملف EXE والمُثبّت على Windows 10/11 بنظام 64-bit.
[ ] اختبر تثبيتاً جديداً وتحديثاً وإلغاء تثبيت على جهاز لا يحتوي Python.
[ ] تأكد أن الاختصار يظهر على سطح المكتب وأن البرنامج يبدأ بعد التثبيت.
[ ] اختبر إنشاء حساب المدير وتسجيل الدخول وإيقاف حساب مستخدم وإعادة تعيين كلمة المرور.
[ ] اختبر إدخال 5000 طالب على الأقل واستيراد CSV بترميز UTF-8 وتكرار أرقام الطلاب.
[ ] اختبر كل تقارير الحضور والدرجات والرسوم وتصدير CSV باستخدام Excel.
[ ] اختبر نسخة ZIP على جهاز ثانٍ مع مرفقات PDF وصور، ثم تأكد من فتح المرفقات المستعادة.
[ ] جهّز عينة بيانات وهمية للعرض ولا تستخدم بيانات أطفال حقيقية في العروض.
[ ] احتفظ بنسخة خارجية آمنة من بيانات كل مدرسة، وخطة استعادة مجرّبة.
[ ] قرر نموذج الترخيص التجاري (ترخيص دائم لكل مدرسة أم اشتراك)، ونفّذ التفعيل قبل البيع إذا أردت منع نسخ غير مرخصة.
[ ] قرر صلاحيات كل دور (مدير، إدارة، مدرس، محاسب) ونفذ منع الوصول داخل الكود؛ الإصدار الحالي يوفّر حسابات دخول ولكن لا يقيّد كل شاشة حسب الدور.
[ ] قيّم تشفير قاعدة البيانات على القرص وفق متطلبات المدرسة؛ كلمات المرور مجزأة، لكن ملف SQLite ومرفقاته ليسا مشفرين.
[ ] وقّع المُثبّت بشهادة توقيع برمجية موثوقة عند التوزيع، أو وضّح للمدرسة طريقة التحقق من مصدر الملف.
[ ] راجع المتطلبات القانونية المحلية لحفظ سجلات الطلاب والدرجات والوثائق وإيصالات الرسوم.

لا تسوّق هذا الإصدار على أنه منصة متعددة الحواسيب متزامنة أو نظام سحابي. قاعدة البيانات محلية على كل حساب Windows، ونقل البيانات بين الحواسيب يتم عبر النسخة الاحتياطية.

- [ ] تم ضبط مستودع GitHub العام واختبار فحص الإصدار من زر «تحديث البرنامج».
- [ ] ملف الإصدار يحتوي على ملف EXE وملف SHA-256 مطابق.
- [ ] جرى اختبار تحديث إصدار أقدم مع التأكد من بقاء قاعدة البيانات والوثائق.
