مدرستي Pro 1.3.0 — ما يتضمنه المشروع
=====================================

- شاشة بداية تحمل شعار المدرسة واسم البرنامج.
- واجهة بألوان كحلي/تركوازي/ذهبي وأيقونات مدرسية وقائمة جانبية واحدة.
- خط قابل للاختيار وحجم من 9 إلى 18، ولون نص وخلفية خانات وخلفية بطاقات قابلة للتغيير، مع حفظ الإعدادات.
- تبديل الوضع الفاتح والداكن.
- إدارة بيانات المدرسة والدوام والصفوف والشعب والمدرسين والمواد والطلاب.
- تسجيل الحضور والغياب والتأخر والإجازة حسب الصف والتاريخ.
- الامتحانات والدرجات وجدول الحصص والرسوم والأقساط.
- أرشيف للملفات والصور مع حفظ المرفقات داخل مجلد بيانات التطبيق، ومعاينة صور وطباعة سجل الأرشيف.
- طباعة القوائم والتقارير، وتصدير CSV، ونسخ احتياطي/استعادة ZIP يشمل قاعدة البيانات والمرفقات.
- زر تحديث يفحص إصدارات GitHub المنشورة ويتحقق من SHA-256 قبل تشغيل المُثبّت.

الجداول تبدأ فارغة عمداً حتى تدخل بيانات مدرستك الحقيقية. ستظهر رسالة إرشادية وأسماء الأعمدة؛ ابدأ بإضافة الصفوف والشعب، ثم المدرسين والمواد، ثم الطلاب.

لم يتم إنتاج مُثبّت Windows نهائي أو اختباره على حاسوب Windows من بيئة التطوير هنا. يجب نشر المصدر وتشغيل GitHub Actions وبناء المُثبّت، ثم اختبار النسخة على جهازك قبل توزيعها.
