مدرستي Pro — واجهة الإصدار 1.2.0 والتحديث التلقائي
====================================================

الواجهة والجداول
----------------
- لوحة رئيسية بالألوان المدرسية (كحلي، تركوازي، ذهبي) مع مؤشرات وخطوات إعداد واضحة.
- شاشة ترحيب بشعار البرنامج واسمه.
- قائمة جانبية بأيقونات تخص المدرسة: الصفوف، المدرسون، المواد، الطلاب، الحضور، الدرجات، جدول الحصص، الرسوم، الأرشيف والتقارير.
- جداول قابلة للإضافة والتحديد والتعديل والحذف. انقر مرتين على سجل لتحميله إلى النموذج أعلى الجدول، ثم اضغط تحديث المحدد لحفظ التعديل.
- لا تُضاف بيانات طلاب تجريبية تلقائياً؛ ابدأ بإضافة بيانات المدرسة ثم الصفوف والشعب، ثم المدرسين والمواد والطلاب.
- عرض عربي محسن للمسميات والجداول، مع دعم الوضع الفاتح والداكن.

نشر الإصدار 1.2.0 في مستودعك الموجود
----------------------------------
1. فك ضغط MadrasatiPro_Professional_UI_1.2.0.zip.
2. انسخ الملفات والمجلدات الناتجة، ثم الصقها داخل مجلد المستودع المحلي MadrasatiPro-Updates الذي فتحته من GitHub Desktop بزر Show in Explorer.
3. إذا سألك Windows عن استبدال ملفات بنفس الاسم، اختر الاستبدال. لا تحذف المجلد المخفي .git ولا ترفع قواعد بيانات المدارس أو النسخ الاحتياطية.
4. افتح GitHub Desktop. في Summary اكتب Upgrade Madrasati Pro UI to 1.2.0، ثم اضغط Commit to main وبعدها Push origin.
5. افتح https://github.com/abode28/MadrasatiPro-Updates، ثم Actions.
6. افتح Build and publish Madrasati Pro update واضغط Run workflow. اكتب 1.2.0 في خانة Version ثم شغّل العملية.
7. انتظر Success، ثم افتح Releases وتأكد من وجود SchoolManagerPro_Setup_1.2.0.exe وملف SHA-256.
8. ثبّت 1.2.0 أول مرة على حاسبتك واختبر الجداول وحفظ البيانات والتحديث. لا توزع النسخة قبل نجاح الاختبار على Windows.

كل تحديث يأتي بعد ذلك
---------------------
1. عدّل كود المشروع ثم ارفع التعديلات إلى المستودع من GitHub Desktop.
2. شغّل سير العمل نفسه برقم إصدار أعلى، مثل 1.2.1 ثم 1.2.2.
3. من النسخ المثبّتة المدعومة، زر «تحديث البرنامج» يفحص أحدث إصدار منشور وينزّله بعد موافقتك.

تنبيه
-----
- زر «تحديث البرنامج» يستقبل إصداراً منشوراً ولا ينشر تعديلات الكود وحده. النشر يتم من GitHub Actions.
- الإصدار الحالي المنشور سابقاً هو 1.1.0؛ لذلك نستخدم إصداراً جديداً 1.2.0.
- بيانات المدرسة موجودة خارج مجلد البرنامج في %LOCALAPPDATA%\SchoolManagerPro\SchoolData، لكن احتفظ دائماً بنسخة احتياطية قبل الترقية.
