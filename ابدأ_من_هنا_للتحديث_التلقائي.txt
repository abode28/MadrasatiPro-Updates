مدرستي Pro — تعليمات الإصدار 1.3.0
===================================

مهم: هذه حزمة مصدر المشروع لتحديث مستودع GitHub، وليست ملف تثبيت Windows.
لا تشغّل ملف تثبيت 1.2.0 القديم لإصلاح الواجهة.

ما الذي أُصلح؟
- معالجة مسار عرض العربية: يمرّ نص Unicode الأصلي على Windows دون قلبه مسبقاً، لتفادي ترتيب الحروف مرتين.
- فصل شريط الأوامر عن العنوان وإخفاء تبويبات Notebook المكررة.
- جعل الصفحة الرئيسية قابلة للتمرير على الشاشات الأقصر.
- إعدادات محفوظة لنوع الخط وحجمه ولون النص ولون الأزرار وخلفيات الحقول والبطاقات.
- جداول فعلية للطلاب والمدرسين والصفوف والمواد والحضور والدرجات والحصص والرسوم، مع إضافة وتعديل وحذف وبحث وطباعة.
- أرشيف لإرفاق الصور والوثائق ومعاينتها وطباعة سجل الأرشيف.

طريقة نشر 1.3.0 على مستودعك الحالي
---------------------------------
1. أغلق مدرستي Pro على الكمبيوتر.
2. فك ضغط الحزمة إلى مجلد منفصل.
3. افتح مجلد المستودع المحلي MadrasatiPro-Updates من GitHub Desktop عبر Repository > Show in Explorer.
4. انسخ ملفات الحزمة إلى جذر المستودع والصقها هناك، ووافق على استبدال ملفات المشروع التي تحمل الاسم نفسه. لا تحذف مجلد .git المخفي. لا تضف قاعدة بيانات المدرسة أو صوراً خاصة أو نسخاً احتياطية.
5. افتح GitHub Desktop. اكتب Summary: Fix Arabic rendering and complete school UI 1.3.0 ثم اضغط Commit to main وبعده Push origin.
6. افتح GitHub > Actions > Build and publish Madrasati Pro update > Run workflow. اختر main وأدخل 1.3.0، ثم شغّل العملية.
7. انتظر Success، وافتح Releases وتأكد من وجود SchoolManagerPro_Setup_1.3.0.exe وملف .sha256.
8. احتفظ بنسخة احتياطية من بيانات المدرسة قبل تجربة المُثبّت، واختبر الإضافة والتعديل والطباعة والصور أولاً على جهازك.

للتحديثات التالية
------------------
بعد أن تنجح هذه النسخة، عدّل ملفات المشروع وارفعها بالطريقة نفسها، واستخدم رقم إصدار أعلى في Actions، مثلاً 1.3.1 ثم 1.3.2. زر «تحديث البرنامج» يجلب إصداراً منشوراً؛ لا ينشر التعديلات بنفسه.

البيانات والسلامة
-----------------
تُحفظ قاعدة البيانات وملفات الأرشيف في %LOCALAPPDATA%\SchoolManagerPro\SchoolData، خارج مجلد التثبيت، حتى لا تُستبدل أثناء ترقية البرنامج. احتفظ بنسخة احتياطية ولا ترفع معلومات الطلاب إلى GitHub.

ملاحظة عن SmartScreen: ملف EXE غير الموقّع قد يظل يعرض Unknown Publisher. نجاح فحص Defender لا يثبت الأمان المطلق؛ شغّل فقط إصداراً تأكدت من مصدره ومن اكتمال بنائه في Actions، ولا تعطّل Microsoft Defender.
