# مدرستي Pro — نظام إدارة المدارس

مشروع Windows مكتبي لإدارة الطلاب والمدرسين والصفوف والمواد والحضور والدرجات والرسوم والجدول والوثائق والتقارير.

## الإصدار الحالي

- نسخة المشروع: `1.1.0`
- مستودع التحديثات: [`abode28/MadrasatiPro-Updates`](https://github.com/abode28/MadrasatiPro-Updates)
- بيانات المدرسة تحفظ محلياً في `%LOCALAPPDATA%\SchoolManagerPro\SchoolData`، ولا ينبغي رفعها إلى GitHub.

## بناء نسخة Windows

على Windows 10/11، ثبّت Python 3.11 أو 3.12 وInno Setup 6، ثم شغّل `build_windows.bat`. سيُنشأ المُثبّت داخل `dist-installer`.

## نشر تحديث يصل إلى النسخ المثبّتة

1. افتح تبويب **Actions** في هذا المستودع.
2. اختر **Build and publish Madrasati Pro update**.
3. اضغط **Run workflow** وأدخل رقم إصدار أعلى من المنشور سابقاً (مثل `1.1.0` لأول إصدار أو `1.1.1` للتالي).
4. بعد نجاح العملية، سيظهر الإصدار في **Releases** مع مُثبّت Windows وبصمة SHA-256.
5. النسخ المثبّتة التي تحتوي على مساعد التحديث ستكتشف الإصدار الجديد عند التشغيل أو من زر **تحديث البرنامج**.

## اختبارات المطور

```powershell
python -m py_compile school_manager.py updater.py
python -m unittest discover -s tests -v
```

> مهم: يلزم نشر أول إصدار ناجح وتجربته على حاسبة اختبار. النسخ القديمة التي لا تحتوي على مساعد التحديث تحتاج تثبيت الترقية الأولى مرة واحدة. لا ترفع قواعد بيانات المدارس أو كلمات المرور أو معلومات الطلاب إلى هذا المستودع.
