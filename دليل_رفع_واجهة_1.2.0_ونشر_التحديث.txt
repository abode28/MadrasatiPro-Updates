مدرستي Pro — تحديث الواجهة ونشر الإصدار 1.2.0
==================================================

هذا الملف يشرح ترقية ملفات المشروع الموجود في مستودعك. لا تضع قاعدة بيانات الطلاب أو النسخ الاحتياطية داخل GitHub.

الملف المطلوب
-------------
MadrasatiPro_Professional_UI_1.2.0.zip

الخطوات على Windows
------------------
1. نزّل ملف ZIP الجديد ثم اضغط عليه بالزر الأيمن واختر Extract All.
2. افتح المجلد الناتج. حدّد محتوياته كلها وانسخها.
3. افتح مجلد المستودع المحلي MadrasatiPro-Updates (المجلد الذي فتحته سابقاً بزر Show in Explorer من GitHub Desktop).
4. الصق الملفات داخله. إذا سألك Windows عن استبدال الملفات المتشابهة، وافق على استبدال الملفات. لا تحذف المجلد المخفي .git ولا تضف بيانات الطلاب.
5. افتح GitHub Desktop. ستظهر قائمة التغييرات. في Summary اكتب: Upgrade Madrasati Pro UI to 1.2.0
6. اضغط Commit to main ثم انتظر، واضغط Push origin.
7. افتح موقع المستودع https://github.com/abode28/MadrasatiPro-Updates ثم Actions.
8. اختر Build and publish Madrasati Pro update ثم Run workflow. اكتب 1.2.0 في Version، واترك ملخص الإصدار الافتراضي، ثم شغّل العملية.
9. انتظر علامة Success. افتح Releases وتأكد من وجود SchoolManagerPro_Setup_1.2.0.exe وملف SHA-256.
10. ثبّت إصدار 1.2.0 أول مرة على جهازك واختبره. بعد نجاحه، تستطيع النسخ المثبّتة التي تدعم التحديث استقبال الإصدارات القادمة من زر تحديث البرنامج.

مهم
----
- الإصدار المنشور 1.1.0 لا يتغير حتى تنفذ خطوات commit/push وتشغّل سير العمل بنجاح.
- زر تحديث البرنامج على حاسبة المدرسة يستقبل تحديثاً منشوراً؛ أما نشر تعديلات الكود فيتم عبر GitHub Desktop وGitHub Actions.
- لم يُبنَ مُثبّت Windows نهائي محلياً في هذه الحزمة؛ سير عمل GitHub Actions يبنيه على Windows. يجب الاختبار على جهاز Windows قبل التوزيع.
